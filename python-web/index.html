PROJECT NOTES

A student prototype,
built with people in mind.

RoadWatch explores how photo reports and machine learning can help organize observations about road damage.

RoadWatch is an academic prototype. It does not replace professional road inspection, emergency services, or official civic complaint systems.

How it works

The Python server stores reports in a local SQLite database and photos in an uploads folder. If a compatible ML service is configured, it can request AI suggestions; without one, it records the report without inventing a detection. Leaflet displays accepted reports on OpenStreetMap.

Responsible use

Location is optional. Avoid faces, license plates, house numbers, or private property details. AI output is a suggestion requiring human review. It does not measure pothole depth, road safety, or repair urgency.
